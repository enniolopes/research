# ADR 0006 — Mindmap and other views are derived

**Status:** Accepted

## Decision

Mindmap, argument map, provenance trace and decision views are on-demand projections of the same accepted scientific state.

## Rationale

Maintaining visual documents as independent truth creates synchronization errors and authoring overhead. Views are valuable as cognitive/navigation interfaces, not as canonical records.

## Consequences

- users can navigate the project visually;
- no workflow step exists solely to keep a mindmap synchronized;
- view rendering can evolve without changing scientific history.
