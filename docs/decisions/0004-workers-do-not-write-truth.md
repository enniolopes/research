# ADR 0004 — Workers propose; control admits

**Status:** Accepted

## Decision

AI workers return typed proposals, observations, evidence, results or critiques. They do not directly promote their own output to accepted scientific truth/state.

## Rationale

A persuasive generator should not be both author and admission authority. Separating cognitive generation from state transition makes scientific controls enforceable independent of model behavior.

## Consequences

- Core owns acceptance transitions;
- worker interfaces need evidence/result references;
- adversarial workers may challenge accepted state without silently rewriting it.
