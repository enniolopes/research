# Review work produced outside research

Use for a third-party paper, report or historical study without this system's native artifacts. Audit what is available before proposing a new study. Do not manufacture a protocol freeze, run manifest or author history, and do not require migration to RESEARCH.map before useful review can begin.

1. Identify the version reviewed and available manuscript, supplements, data, code and registration. Preserve original material. Record access limits and locators.
2. Extract material claims with source locations; separate the authors' statements, the reviewer's reconstruction and independently reproduced findings. A reported number is a cited result, not a computation executed by this system.
3. Reconstruct the smallest question → measure/design → evidence → inference chain needed to assess each claim. Apply the inference bridge only where relevant. Missing native annotations are not a scientific defect.
4. For each claim distinguish a demonstrated error/overclaim, a plausible unresolved vulnerability, and unavailable verification. Missing information alone establishes neither falsity nor misconduct. Preserve justified conclusions and identify the smallest resolving action; report irreducible disagreement rather than inventing certainty.
5. Send inspectable material to reviewer-2 in external-review mode for independent review. A separate context is procedural independence, not a guarantee against shared model/source errors. If unavailable, label the product an authoring-context assessment with independent review NOT_VERIFIED; still deliver the useful inspection.
6. Save the review as its own artifact, linked to the reviewed version. If reanalysis is authorized and feasible, record its own inputs/code/results separately and compare against the authors' claim. Do not silently edit the source or recast a new analysis as reproduction.

Start the user-facing review with the question, conclusion allowed by available evidence, decisive support, main limitation and next resolving action. Follow with claim-level findings and exact locations. Overall verdicts must not conceal that different claims have different evidential status.

Apply the discipline appropriate to the actual design. Do not impose observational reporting checklists on unrelated designs or claim expertise beyond the material inspected. Material unfamiliar methodology requires primary-source inspection or specialist review; localize that limit rather than blocking unrelated findings.
