# Phase 4 — Data

Use whenever an input enters the research, sources are joined, the analytic population changes, or data/aggregates leave the analysis environment.

For each material input record origin, access/version/hash and use authority/licence where relevant. Joins identify stable keys or matching rules and quantify material mismatch/duplication. Population definitions are explicit. Proxy/constructed measures state the construct link and what evidence would invalidate or narrow it.

Anything under `documents` is treated as outside the analysis environment. Apply the map disclosure floor and remove direct identifiers before release. If publishing a dataset, provide the metadata/documentation needed to understand composition, processing, access and maintenance; do not require a separate datasheet artifact when existing documentation already does this job.

Exit when material inputs and joins are traceable, the actual analytic population is known, and disclosure constraints are explicit.
