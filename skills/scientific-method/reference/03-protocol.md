# Phase 3 — Protocol

Use after the problem is established and before confirmatory exposure.

For each confirmatory hypothesis record the estimand, prediction, refutation/decision rule and exactly one primary test. Add only secondary/specification alternatives that are prospectively defensible, preserve the estimand and could materially change inference; do not enumerate every imaginable analytic choice.

Fix bounds before any claim of equivalence/no-effect. State identification assumptions for causal language and downgrade to associational wording when they cannot be defended. Thresholds or cut-offs need a stated basis.

Derive the registration from the protocol and freeze it in Git. Until registration is valid, confirmatory execution remains DRY_RUN or exploratory according to the project contract.

Exit when the scientific commitments needed by the analysis plan are explicit and frozen. Any later material change routes through CHANGE_PLAN.
